# forgetrace

Forge lightweight trace statistics from stdin samples.

**Site:** https://theworker02.github.io/forgetrace/

## Install / run

```bash
git clone https://github.com/theworker02/forgetrace.git
cd forgetrace
node src/cli.js
node --test
```
